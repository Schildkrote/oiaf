# Active Directory Monitoring

Monitors Active Directory for suspicious authentication patterns and privilege escalation.

## Use Case

- AD Monitor adapter watches authentication events in real time
- Detects anomalies: impossible travel, privilege escalation, service account misuse
- Triggers alerts and automated responses (session revocation, MFA enforcement)
- Feeds risk engine with behavioral signals

## Relevant Adapters

- **AD Monitor Adapter** — passive monitoring of AD authentication events
- See `docs/adapters/ad-monitor.md` for configuration details
