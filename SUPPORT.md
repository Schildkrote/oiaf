# Support

## Bugs

Report bugs via [GitHub Issues](https://github.com/oiaf/oiaf/issues). Please
include reproduction steps, expected vs. actual behavior, and version info.

## Questions

Ask questions and share ideas in
[GitHub Discussions](https://github.com/oiaf/oiaf/discussions).

## Security Issues

For security vulnerabilities, do **not** open a public issue. Follow the
private reporting process in [SECURITY.md](SECURITY.md).
